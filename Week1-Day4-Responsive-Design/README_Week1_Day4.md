# Week 1 - Day 4: Responsive Design & Media Queries

## Objective

Build a fully responsive webpage using a mobile-first approach.

## Features

- Mobile-first layout
- Media Queries
- Responsive navigation
- Responsive cards
- Relative units (rem, %)
- Hover effects

## Breakpoints

- Mobile: 320px
- Tablet: 768px
- Desktop: 1200px

## Technologies

- HTML5
- CSS3

## Learning Outcome

- Learned Mobile First Design
- Used Media Queries
- Created Responsive Layout
