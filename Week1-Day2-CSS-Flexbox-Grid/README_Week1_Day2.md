# Week 1 – Day 2: CSS Fundamentals – Flexbox & Grid

## Objective

Learn how to build responsive layouts using CSS Flexbox and CSS Grid.

## Features

- Responsive navigation bar using Flexbox
- Three-column card layout using CSS Grid
- Hover effects
- CSS transitions
- Mobile responsive design

## Technologies Used

- HTML5
- CSS3
- VS Code

## How to Run

1. Download the project.
2. Open the folder in VS Code.
3. Open index.html in your browser.

## Learning Outcome

- Learned Flexbox layout.
- Learned Grid layout.
- Built responsive webpage.
- Applied hover effects and transitions.
