# Week 1 - Day 3: JavaScript ES6+ Basics

## Objective

Learn modern JavaScript (ES6+) features.

## Features

- Arrow Functions
- Template Literals
- Object Destructuring
- Array Methods
- filter()
- map()
- reduce()
- Event Listeners

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6

## How to Run

1. Open the project in VS Code.
2. Open index.html in your browser.
3. Click the **Show Employee Data** button.

## Learning Outcome

- Learned ES6 syntax
- Used filter(), map(), reduce()
- Built an interactive component
